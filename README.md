## 속도를 어떻게 세는가

**한글은 두벌식 자소 기준이다.** 글자 수로 세면 400타짜리 실력이 100타로 찍힌다.

- `동` = ㄷ + ㅗ + ㅇ = **3타**
- `과` = ㄱ + ㅗ + ㅏ = **3타** (복합모음 ㅘ는 두 번 누른다)
- `닳` = ㄷ + ㅏ + ㄹ + ㅎ = **4타** (겹받침 ㅀ도 두 번)
- `까` = ㄲ + ㅏ = **2타** (쌍자음은 Shift 조합이라 1타)

유니코드 한글 음절을 초성·중성·종성으로 분해해 계산한다.

**영문은 국제 표준 WPM이다.** `(친 글자 ÷ 5) ÷ 분`. 5자를 한 단어로 본다.

두 단위는 서로 다른 척도라 지문에 따라 큰 숫자와 설명, 기록표 헤더가 함께 바뀐다.

## 한글 IME 처리

`동`을 치려면 ㄷ → 도 → 동을 거친다. 조합 중인 글자를 매 순간 정답과 비교하면 화면이 계속 빨갛게 깜빡인다.

그래서 **조합 중인 마지막 글자는 자소 배열이 목표 글자의 앞부분인지만 본다.** 앞부분이면 아직 틀린 게 아니므로 진행 표시(파란 밑줄)로 두고, 어긋나는 순간 오답으로 바꾼다. `돈`을 치면 종성이 어긋나는 즉시 빨간색이 된다.

## 조작

| 키 | 동작 |
|---|---|
| `Enter` | 다음 줄 |
| `Esc` | 그만두기 — 친 데까지 기록으로 남길 수 있다 (한 줄도 안 쳤으면 그냥 처음부터) |
| `←` `→` | 지문 전환 (선택 컨트롤에 포커스가 있을 때) |

붙여넣기는 막혀 있다. 내 최고 기록은 지문별로 `localStorage`에 남는다. 기록판에 올리는 것은 별개이고, 올릴지 말지는 완주 후에 고른다.

## 기록판

완주하면 닉네임을 물어본다. **중간에 `Esc` 로 그만둬도** 친 데까지 기록을 남길 수 있다.
올려도 되고 **「괜찮아요」로 거절해도 된다** — 거절하면 아무것도 전송하지 않는다.

순위는 지문마다 따로 매겨진다. 애국가 571타와 게티즈버그 WPM은 서로 비교할 수 없는
숫자이기 때문이다. 그리고 **끝까지 친 기록이 항상 위에 온다.** 짧게 치다 멈추면 타수가
잘 나오기 때문에, 타수만으로 줄을 세우면 2줄 스프린트가 완주 기록을 밀어낸다.

백엔드는 **Cloudflare Worker + D1** 하나다. 설정과 배포는 [`board/README.md`](board/README.md).
`index.html` 위쪽 `BOARD_API` 가 비어 있으면 기록판이 통째로 꺼지고 나머지는 그대로 돈다.

정적 사이트의 기록판은 원리상 조작을 완벽히 막을 수 없다. 「말도 안 되는 값」을
DB 제약으로 막는 선(L1)에서 멈췄고, 무엇을 막고 무엇을 못 막는지는 board README에 적어뒀다.

## 파일

```
index.html      게임 전부 (마크업 + CSS + 로직)
tokens.css      색·타이포·간격 토큰
board/          기록판 API — Cloudflare Worker + D1
  worker.js       API
  schema.sql      테이블 + 검증 제약
  wrangler.toml   배포 설정
```

빌드 단계가 없다. `index.html`을 브라우저로 열면 그대로 돌아간다.

지문을 추가하려면 `index.html`의 `LANGS.<언어>.texts`에 항목 하나를 넣으면 된다. 드롭다운은 그 목록에서 자동으로 만들어지므로 마크업은 건드릴 필요가 없다.

## 지문을 고른 기준

**저작권.** 한국은 사후 70년이라 1962년 이전에 사망한 작가만 안전하다. 김소월(1934)·윤동주(1945)·이육사(1944)는 만료됐다. 염상섭은 1963년 사망이라 2033년까지 보호되므로 쓰지 않았다. 헌법·법률은 저작권법 제7조로 보호 대상 자체가 아니다.

**자판으로 칠 수 있을 것.** 타자연습 지문에 입력 불가능한 문자가 있으면 연습이 성립하지 않는다. 실제로 걸린 것들:

- 「진달래꽃」 1925년 초간본은 **옛한글**(`ᄭᅩᆺ`, `ᄯᅢ`)이라 현대 자판으로 입력 자체가 안 된다 → 현행 맞춤법 표기 사용
- 「청포도」의 한자 병기 `靑袍` → 생략
- 헌법의 **가운뎃점**(`·`)과 **동그라미 숫자**(`①`)는 표준 자판에 키가 없다 → `·`가 든 제6·8·9조 제외, 항 번호는 지우고 항마다 줄을 나눔
- 게티즈버그 연설의 **em dash**(`—`) → 그 자리에서 줄을 끊음. 단어와 문장부호는 그대로

모든 지문의 모든 글자가 표준 자판(두벌식 + 영문)으로 입력 가능한지 스크립트로 검사한다.

**원문은 전부 [위키문헌](https://ko.wikisource.org)에서 받았다.** 기억으로 쓰지 않았다 — 지문에 오타가 있으면 사용자가 오타를 강제로 따라 쳐야 하기 때문이다. 손댄 부분은 위 표와 화면 하단에 전부 명시했다.
