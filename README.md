# 타자연습

웹에서 바로 치는 한글·영문 타자연습. 서버 없이 정적 파일로만 돌아간다.

**→ https://loong-kid.github.io/typing-practice/**

## 지문

| 지문 | 줄 | 분량 | 속도 단위 |
|---|---|---|---|
| 대한민국 애국가 1–4절 | 16줄 | 571타 | 타 / 분 |
| The Gettysburg Address (1863) | 32줄 | 1421타 | WPM |

## 속도를 어떻게 세는가

**한글은 두벌식 자소 기준이다.** 글자 수로 세면 400타짜리 실력이 100타로 찍힌다.

- `동` = ㄷ + ㅗ + ㅇ = **3타**
- `과` = ㄱ + ㅗ + ㅏ = **3타** (복합모음 ㅘ는 두 번 누른다)
- `닳` = ㄷ + ㅏ + ㄹ + ㅎ = **4타** (겹받침 ㅀ도 두 번)
- `까` = ㄲ + ㅏ = **2타** (쌍자음은 Shift 조합이라 1타)

유니코드 한글 음절을 초성·중성·종성으로 분해해 계산한다.

**영문은 국제 표준 WPM이다.** `(친 글자 ÷ 5) ÷ 분`. 5자를 한 단어로 본다.

두 단위는 서로 다른 척도라 지문에 따라 큰 숫자와 설명, 기록표 헤더가 함께 바뀐다.

## 한글 IME 처리

`동`을 치려면 ㄷ → 도 → 동을 거친다. 조합 중인 글자를 매 순간 정답과 비교하면 화면이 계속 빨갛게 깜빡인다.

그래서 **조합 중인 마지막 글자는 자소 배열이 목표 글자의 앞부분인지만 본다.** 앞부분이면 아직 틀린 게 아니므로 진행 표시(파란 밑줄)로 두고, 어긋나는 순간 오답으로 바꾼다. `돈`을 치면 종성이 어긋나는 즉시 빨간색이 된다.

## 조작

| 키 | 동작 |
|---|---|
| `Enter` | 다음 줄 |
| `Esc` | 처음부터 |
| `←` `→` | 지문 전환 (선택 컨트롤에 포커스가 있을 때) |

붙여넣기는 막혀 있다. 최고 기록은 지문별로 `localStorage`에 남는다 — 서버로 아무것도 보내지 않는다.

## 파일

```
index.html   게임 전부 (마크업 + CSS + 로직)
tokens.css   색·타이포·간격 토큰
```

빌드 단계가 없다. `index.html`을 브라우저로 열면 그대로 돌아간다.

지문을 추가하려면 `index.html`의 `COURSES` 객체에 항목을 넣으면 된다. 선택 버튼은 지금 마크업에 직접 적혀 있어서 그 부분만 같이 손보면 된다.

## 출처와 편집 고지

- **애국가** — 작사자 미상, 퍼블릭 도메인.
- **게티즈버그 연설** — 링컨, 1863 (Bliss 사본). 퍼블릭 도메인. 원문의 em dash(`—`)는 표준 자판으로 칠 수 없어 **그 자리에서 줄을 끊었다.** 단어와 문장부호는 하나도 바꾸지 않았다.
